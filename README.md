# Caliber Inbox

A personal tool that sorts my own Gmail inbox (and, later, my own Slack messages) by what needs my
attention. It is used only by me, Anthony Lamelas, and is not offered to anyone else.

## Privacy policy

- **What it reads:** messages in my own Gmail account, through Google's Gmail API, after I sign in and
  approve access. It reads no one else's account.
- **What it does with them:** groups messages into conversations, labels each one (needs reply, to do,
  waiting, FYI, noise) and drafts replies that I review. It sends a reply only when I click Send.
- **Where the data goes:** into my own private Caliber deployment. Message text is sent to Anthropic's
  Claude API to label conversations and draft replies, under Anthropic's API terms (no training on API data).
- **Sharing:** the data is never sold, shared, or used for advertising.
- **Removal:** I can revoke access at any time at https://myaccount.google.com/permissions, and delete
  the stored data from my deployment.

Use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
